# @depup/express-slow-down

> [express-slow-down](https://www.npmjs.com/package/express-slow-down) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/express-slow-down
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 3.1.0 | **DepUp version**: 3.1.0-depup.0 | **Updated**: 3/19/2026 | **Import test**: passed
