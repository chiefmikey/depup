# @depup/react-select

> [react-select](https://www.npmjs.com/package/react-select) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/react-select
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 5.10.2 | **DepUp version**: 5.10.2-depup.1 | **Updated**: 3/16/2026 | **Import test**: unknown
