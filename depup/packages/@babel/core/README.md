# @depup/babel__core

> [@babel/core](https://www.npmjs.com/package/@babel/core) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/babel__core
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 7.29.0 | **DepUp version**: 7.29.0-depup.2 | **Updated**: 3/16/2026 | **Import test**: unknown
