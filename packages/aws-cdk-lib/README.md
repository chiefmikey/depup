# @depup/aws-cdk-lib

> [aws-cdk-lib](https://www.npmjs.com/package/aws-cdk-lib) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/aws-cdk-lib
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 2.262.0 | **DepUp version**: 2.262.0-depup.0 | **Updated**: 7/23/2026 | **Import test**: passed
