# @depup/eslint-plugin-import

> [eslint-plugin-import](https://www.npmjs.com/package/eslint-plugin-import) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/eslint-plugin-import
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 2.32.0 | **DepUp version**: 2.32.0-depup.21 | **Updated**: 6/15/2026 | **Import test**: passed
