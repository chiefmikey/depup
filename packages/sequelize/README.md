# @depup/sequelize

> [sequelize](https://www.npmjs.com/package/sequelize) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/sequelize
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 6.37.8 | **DepUp version**: 6.37.8-depup.24 | **Updated**: 3/14/2026 | **Import test**: unknown
