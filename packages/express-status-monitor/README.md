# @depup/express-status-monitor

> [express-status-monitor](https://www.npmjs.com/package/express-status-monitor) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/express-status-monitor
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 1.3.4 | **DepUp version**: 1.3.4-depup.4 | **Updated**: 6/3/2026 | **Import test**: passed
