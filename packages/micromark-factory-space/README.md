# @depup/micromark-factory-space

> [micromark-factory-space](https://www.npmjs.com/package/micromark-factory-space) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/micromark-factory-space
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 2.0.1 | **DepUp version**: 2.0.1-depup.0 | **Updated**: 3/17/2026
