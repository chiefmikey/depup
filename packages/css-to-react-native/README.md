# @depup/css-to-react-native

> [css-to-react-native](https://www.npmjs.com/package/css-to-react-native) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/css-to-react-native
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 3.2.0 | **DepUp version**: 3.2.0-depup.0 | **Updated**: 3/17/2026
