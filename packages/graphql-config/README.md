# @depup/graphql-config

> [graphql-config](https://www.npmjs.com/package/graphql-config) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/graphql-config
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 5.1.8 | **DepUp version**: 5.1.8-depup.1 | **Updated**: 10/15/2026 | **Import test**: passed
