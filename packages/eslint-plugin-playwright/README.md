# @depup/eslint-plugin-playwright

> [eslint-plugin-playwright](https://www.npmjs.com/package/eslint-plugin-playwright) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/eslint-plugin-playwright
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 2.10.5 | **DepUp version**: 2.10.5-depup.7 | **Updated**: 7/14/2026 | **Import test**: passed
