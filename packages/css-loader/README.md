# @depup/css-loader

> [css-loader](https://www.npmjs.com/package/css-loader) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/css-loader
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 7.1.4 | **DepUp version**: 7.1.4-depup.34 | **Updated**: 6/25/2026 | **Import test**: passed
