# @depup/vue__language-core

> [@vue/language-core](https://www.npmjs.com/package/@vue/language-core) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/vue__language-core
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 3.2.8 | **DepUp version**: 3.2.8-depup.0 | **Updated**: 5/5/2026 | **Import test**: passed
