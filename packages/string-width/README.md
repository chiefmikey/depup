# @depup/string-width

> [string-width](https://www.npmjs.com/package/string-width) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/string-width
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 8.2.1 | **DepUp version**: 8.2.1-depup.10 | **Updated**: 6/11/2026 | **Import test**: passed
