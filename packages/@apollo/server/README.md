# @depup/apollo__server

> [@apollo/server](https://www.npmjs.com/package/@apollo/server) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/apollo__server
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 5.5.0 | **DepUp version**: 5.5.0-depup.2 | **Updated**: 4/19/2026 | **Import test**: passed
