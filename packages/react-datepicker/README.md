# @depup/react-datepicker

> [react-datepicker](https://www.npmjs.com/package/react-datepicker) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/react-datepicker
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 9.1.0 | **DepUp version**: 9.1.0-depup.3 | **Updated**: 5/30/2026 | **Import test**: passed
