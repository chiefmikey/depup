# @depup/microbundle

> [microbundle](https://www.npmjs.com/package/microbundle) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/microbundle
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 0.15.1 | **DepUp version**: 0.15.1-depup.36 | **Updated**: 6/17/2026 | **Import test**: failed
