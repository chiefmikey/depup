# @depup/html-minifier-terser

> [html-minifier-terser](https://www.npmjs.com/package/html-minifier-terser) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/html-minifier-terser
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 7.2.0 | **DepUp version**: 7.2.0-depup.6 | **Updated**: 8/26/2026 | **Import test**: passed
