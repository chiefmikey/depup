# @depup/sentry__cli

> [@sentry/cli](https://www.npmjs.com/package/@sentry/cli) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/sentry__cli
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 3.5.0 | **DepUp version**: 3.5.0-depup.24 | **Updated**: 6/14/2026 | **Import test**: passed
