# @depup/sentry__node

> [@sentry/node](https://www.npmjs.com/package/@sentry/node) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/sentry__node
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 10.69.0 | **DepUp version**: 10.69.0-depup.0 | **Updated**: 7/29/2026 | **Import test**: passed
