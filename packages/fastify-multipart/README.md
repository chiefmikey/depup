# @depup/fastify-multipart

> [fastify-multipart](https://www.npmjs.com/package/fastify-multipart) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/fastify-multipart
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 5.3.1 | **DepUp version**: 5.3.1-depup.0 | **Updated**: 3/19/2026 | **Import test**: passed
