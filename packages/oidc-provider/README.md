# @depup/oidc-provider

> [oidc-provider](https://www.npmjs.com/package/oidc-provider) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/oidc-provider
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 9.7.1 | **DepUp version**: 9.7.1-depup.2 | **Updated**: 4/2/2026 | **Import test**: passed

## About DepUp

[DepUp](https://github.com/depup/npm) is an automated package factory that publishes dependency-bumped versions of 1000+ popular npm packages.
