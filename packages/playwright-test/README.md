# @depup/playwright-test

> [playwright-test](https://www.npmjs.com/package/playwright-test) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/playwright-test
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 15.0.1 | **DepUp version**: 15.0.1-depup.0 | **Updated**: 9/26/2026 | **Import test**: passed
