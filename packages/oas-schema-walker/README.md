# @depup/oas-schema-walker

> [oas-schema-walker](https://www.npmjs.com/package/oas-schema-walker) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/oas-schema-walker
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 1.1.5 | **DepUp version**: 1.1.5-depup.0 | **Updated**: 3/17/2026
