# @depup/auth__core

> [@auth/core](https://www.npmjs.com/package/@auth/core) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/auth__core
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 0.41.3 | **DepUp version**: 0.41.3-depup.0 | **Updated**: 7/21/2026 | **Import test**: passed
