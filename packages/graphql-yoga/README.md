# @depup/graphql-yoga

> [graphql-yoga](https://www.npmjs.com/package/graphql-yoga) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/graphql-yoga
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 5.21.2 | **DepUp version**: 5.21.2-depup.52 | **Updated**: 7/13/2026 | **Import test**: passed
