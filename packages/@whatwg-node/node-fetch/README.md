# @depup/whatwg-node__node-fetch

> [@whatwg-node/node-fetch](https://www.npmjs.com/package/@whatwg-node/node-fetch) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/whatwg-node__node-fetch
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 0.8.6 | **DepUp version**: 0.8.6-depup.2 | **Updated**: 6/9/2026 | **Import test**: passed
