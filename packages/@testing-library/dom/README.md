# @depup/testing-library__dom

> [@testing-library/dom](https://www.npmjs.com/package/@testing-library/dom) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/testing-library__dom
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 10.4.1 | **DepUp version**: 10.4.1-depup.2 | **Updated**: 7/21/2026 | **Import test**: passed
