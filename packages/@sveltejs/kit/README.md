# @depup/sveltejs__kit

> [@sveltejs/kit](https://www.npmjs.com/package/@sveltejs/kit) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/sveltejs__kit
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 2.65.0 | **DepUp version**: 2.65.0-depup.5 | **Updated**: 6/13/2026 | **Import test**: passed
