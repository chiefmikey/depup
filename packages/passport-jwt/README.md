# @depup/passport-jwt

> [passport-jwt](https://www.npmjs.com/package/passport-jwt) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/passport-jwt
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 4.0.1 | **DepUp version**: 4.0.1-depup.9 | **Updated**: 6/12/2026 | **Import test**: passed
