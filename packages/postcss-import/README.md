# @depup/postcss-import

> [postcss-import](https://www.npmjs.com/package/postcss-import) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/postcss-import
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 17.0.0 | **DepUp version**: 17.0.0-depup.0 | **Updated**: 8/15/2026 | **Import test**: passed
