# @depup/passport-saml

> [passport-saml](https://www.npmjs.com/package/passport-saml) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/passport-saml
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 3.2.4 | **DepUp version**: 3.2.4-depup.4 | **Updated**: 8/11/2026 | **Import test**: passed
