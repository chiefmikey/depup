# @depup/dockerode-compose

> [dockerode-compose](https://www.npmjs.com/package/dockerode-compose) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/dockerode-compose
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 1.4.0 | **DepUp version**: 1.4.0-depup.2 | **Updated**: 6/1/2026 | **Import test**: passed
