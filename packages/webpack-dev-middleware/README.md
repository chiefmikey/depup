# @depup/webpack-dev-middleware

> [webpack-dev-middleware](https://www.npmjs.com/package/webpack-dev-middleware) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/webpack-dev-middleware
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 7.4.5 | **DepUp version**: 7.4.5-depup.0 | **Updated**: 3/17/2026
