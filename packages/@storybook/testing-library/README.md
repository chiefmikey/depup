# @depup/storybook__testing-library

> [@storybook/testing-library](https://www.npmjs.com/package/@storybook/testing-library) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/storybook__testing-library
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 0.2.2 | **DepUp version**: 0.2.2-depup.1 | **Updated**: 6/10/2026 | **Import test**: passed
