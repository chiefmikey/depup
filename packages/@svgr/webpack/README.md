# @depup/svgr__webpack

> [@svgr/webpack](https://www.npmjs.com/package/@svgr/webpack) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/svgr__webpack
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 8.1.0 | **DepUp version**: 8.1.0-depup.1 | **Updated**: 5/25/2026 | **Import test**: passed
