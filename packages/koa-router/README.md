# @depup/koa-router

> [koa-router](https://www.npmjs.com/package/koa-router) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/koa-router
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 14.0.0 | **DepUp version**: 14.0.0-depup.1 | **Updated**: 3/26/2026 | **Import test**: passed
