# @depup/pino-pretty

> [pino-pretty](https://www.npmjs.com/package/pino-pretty) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/pino-pretty
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 13.1.3 | **DepUp version**: 13.1.3-depup.0 | **Updated**: 3/8/2026 | **Import test**: unknown
