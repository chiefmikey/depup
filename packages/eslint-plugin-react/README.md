# @depup/eslint-plugin-react

> [eslint-plugin-react](https://www.npmjs.com/package/eslint-plugin-react) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/eslint-plugin-react
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 7.37.5 | **DepUp version**: 7.37.5-depup.45 | **Updated**: 7/4/2026 | **Import test**: passed
