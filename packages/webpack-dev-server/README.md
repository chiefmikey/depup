# @depup/webpack-dev-server

> [webpack-dev-server](https://www.npmjs.com/package/webpack-dev-server) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/webpack-dev-server
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 5.2.3 | **DepUp version**: 5.2.3-depup.3 | **Updated**: 3/26/2026 | **Import test**: passed
