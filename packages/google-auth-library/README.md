# @depup/google-auth-library

> [google-auth-library](https://www.npmjs.com/package/google-auth-library) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/google-auth-library
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 10.7.0 | **DepUp version**: 10.7.0-depup.28 | **Updated**: 6/19/2026 | **Import test**: passed
