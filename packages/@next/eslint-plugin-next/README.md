# @depup/next__eslint-plugin-next

> [@next/eslint-plugin-next](https://www.npmjs.com/package/@next/eslint-plugin-next) with all dependencies updated to latest versions.

Drop-in replacement. Same API. Fresher dependencies.

```bash
npm install @depup/next__eslint-plugin-next
```

## Why?

Outdated transitive dependencies are the #1 source of npm security vulnerabilities. Most package maintainers don't bump their deps on every patch. DepUp does it automatically -- every 4 hours.

**Original version**: 16.3.3 | **DepUp version**: 16.3.3-depup.0 | **Updated**: 8/25/2026 | **Import test**: passed
